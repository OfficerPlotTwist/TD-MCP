# Authorization and human choices

Execute explicitly requested routine parameter changes and necessary reversible fixes within the user's scope. Do not ask again for an already authorized action. Checkpoint before risky edits.

Clarify genuinely ambiguous direction or destructive work outside the authorized scope. Preserve unresolved visual selections and project choices; do not replace them with arbitrary defaults. Background completion notifications are not approval.

Use any decision-routing system required by the active workspace. The general TD MCP bridge itself has no dependency on a particular approval service or workflow manager.
